# 練習用ファイル配布ページ

『Python未経験でも大丈夫 毎月のExcel作業をダブルクリックで終わらせる本』で使う練習用ファイルと、完成版コードの配布ページです。

## ダウンロード

▶ **[練習用ファイルをダウンロード（excel_auto_practice.zip）](https://github.com/takimprove/excel-auto-book/raw/main/excel_auto_practice.zip)**

## 使い方

1. 上のリンクからZIPファイルをダウンロードする
2. ZIPファイルを右クリック →「すべて展開」
3. 展開してできたフォルダを開き、**中身をすべて**、1章で作った「excel_auto」フォルダに移す

移したあと、「excel_auto」フォルダが次のようになっていれば準備完了です。

```
excel_auto
├── 商品一覧_9月.xlsx
├── 商品一覧_10月.xlsx
├── 売上
│   ├── 売上_01月.xlsx
│   ├── 売上_02月.xlsx
│   └── 売上_03月.xlsx
└── 完成版コード
```

## 入っているもの

| ファイル | 使う章 |
| --- | --- |
| 商品一覧_9月.xlsx / 商品一覧_10月.xlsx | 2章・4章 |
| 売上フォルダ（1月〜3月の売上） | 3章 |
| 完成版コード | 本と同じコード。動かないときの見比べ用 |

練習用ファイルの店舗・商品・数字はすべて架空のものです。
